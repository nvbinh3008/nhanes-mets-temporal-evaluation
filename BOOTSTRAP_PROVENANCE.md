# Bootstrap provenance

**RC2 blocks the historical modeling workflow.** The installed nhanes-model CLI exits with code 2 for temporal-evaluate, nested-validate, run-development and fit-final before reading a configuration or study input. The guard applies when historical debug or resume options are present. Help and configuration-only nhanes-full preflight are available. There is no bypass flag. The original frozen source archive is the historical execution reference. RC2's changed CLI source would also change a source-tree fingerprint. Use the original code and corresponding archive for any authorized historical investigation.

**Exact interval recomputation requires authorized private study inputs.** Phase B metrics depend on fixed OOF and temporal prediction Parquets, cycle and PSU/stratum fields, linked R5 cohort features, and harmonized and derived cycle records for subgroup and glucose-scale sensitivity work. The calibration and comparison scripts require the applicable frozen predictions and, for exploratory contrasts, archived comparator predictions and selection weights. Use an authorized archive and a separate writable output root. See [execution scope](EXECUTION_SCOPE.md).

These intervals condition on observed predictions and omit uncertainty from model selection, fitting and recalibration. Development OOF predictions come from multiple fold fits, whereas the temporal estimates use the final frozen object. Day 1 is primary, with two-day sensitivity. Historical timing of the first outcome access remains independently unverified.
